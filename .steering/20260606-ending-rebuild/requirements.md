# 要求内容

## 概要

現行のエンディング演出（`ALL_CLEAR` フェーズ）を**1から作り直す**。盤面マップを背景に出さず、星空を舞台に「宇宙飛行士が歩いて宇宙船に乗り込み → 発進 → ワープ → 青い地球へ帰還」という一本のアニメーションシーンとして、映像中心で作り込む。

## 背景

現行のエンディングは盤面マップを背景に残したまま、テキストパネル中心で「回収完了→修理→発進→エピローグ」を見せている（`renderer.ts` の `drawEnding` / `drawEndingEpilogue`、9秒）。宇宙飛行士が乗り込む動きが無く、簡易ロケットとワープラインだけの静的な演出にとどまり、ストーリーモード（遭難→部品回収→帰還）の締めくくりとして期待に届いていない。

「故郷へ還る」というストーリーの感情的なクライマックスを、キャラクターの動き（乗船）と到達先（地球）の描写を伴う映像演出として作り直し、プレイ体験の満足度を高める。

## 実装対象の機能

### 1. マップを出さない帰還シーン演出

- `ALL_CLEAR` フェーズで盤面マップを描画せず、既存の星空背景（`Starfield`）のみを舞台にする。
- 以下6段階の絵コンテを timer 駆動で連続再生する（決定論的にし、`performance.now` 依存を避ける）。
  - A 着陸(0.0–1.5s): 地表（ホライズン）＋停泊中の宇宙船＋飛行士が画面にフェードイン。
  - B 歩行(1.5–4.5s): 飛行士が船まで右へ歩き（歩行アニメ）、ハッチへ消えて乗船。
  - C 点火(4.5–6.0s): ハッチ閉・スラスター点火・画面シェイク立ち上げ。
  - D 発進(6.0–7.5s): 機体が上昇して画面外へ。シェイク減衰。
  - E ワープ(7.5–10.0s): 星を加速（`setWarp`）＋ワープライン。終盤で減速。
  - F 帰還(10.0–13.5s): ワープを抜け、青い地球が出現して接近していく画で締める。
- 段階境界に同期して効果音・パーティクルを1回ずつ発火する（乗船音 / 発進音＋噴射バースト / 帰還ファンファーレ）。

### 2. 映像中心の締め（テキストは導線のみ）

- 物語の締めテキスト（エピローグ文）は表示しない。
- シーンの最後（帰還段階）にのみ `Press SPACE / Tap` の開始導線を表示する。

### 3. 演出尺の延長

- エンディング全体の尺を現行9秒から約13.5秒へ延長し、乗船・発進・帰還を丁寧に見せる。
- 尺の延長後も `ALL_CLEAR` 終了でタイトルへ戻る既存遷移を維持する。

## 受け入れ条件

### マップを出さない帰還シーン演出

- [ ] `ALL_CLEAR` フェーズで盤面マップ（通路・壁・ドット）が一切描画されず、背景が星空のみである。
- [ ] 飛行士が地表から船まで歩いて移動し、ハッチに到達して乗船する動きが視認できる。
- [ ] 乗船後に点火・発進し、機体が上昇して画面外へ消える。
- [ ] 発進後にワープ（星の加速＋ワープライン）が再生され、終盤で減速する。
- [ ] ワープ後に青い地球が出現し、接近していく描写でシーンが締まる。
- [ ] 各段階の効果音・パーティクルが、対応する段階境界で過不足なく1回ずつ発火する。
- [ ] 6段階が timer 駆動で途切れず連続再生され、再生のたびに同じ結果になる（決定論的）。

### 映像中心の締め

- [ ] エンディング中に物語の締めテキスト（エピローグ文）が表示されない。
- [ ] 帰還段階の最後に `Press SPACE / Tap` 導線のみが表示される。

### 演出尺の延長

- [ ] エンディング全体の尺が約13.5秒である。
- [ ] エンディング終了後、既存どおりタイトル画面へ遷移する。
- [ ] 既存のゲームフローテスト（特にエンディングの効果音発火テスト）が新しい段階構成で緑になる。

## 成功指標

- 帰還シーンが「乗船 → 発進 → ワープ → 地球帰還」の流れとして意図どおり再生され、ストーリーの締めくくりとして成立している（定性）。
- 盤面マップが背景に残らず、星空のみの舞台で演出が完結している（定性）。
- TypeScript ビルドエラーが無く、既存ユニットテストが全て緑（定量）。

## スコープ外

以下はこのフェーズでは実装しません:

- ゲーム本編（`PLAYING`・ステージ進行・部品回収ロジック）の変更。
- オープニング（`drawIntro`）・タイトル演出の変更。
- 新規アセット（画像・音源ファイル）の追加。演出は Canvas の手続き描画と既存効果音のみで構成する。

## 未決事項

実装フェーズ（`/add-feature` の設計）で判断・確認する点:

- 各段階の境界秒の最終調整（A〜F の配分。提案値: 1.5 / 4.5 / 6.0 / 7.5 / 10.0 / 13.5）。
- 地表（ホライズン）と青い地球の描画スタイル（色・大気グローの強さ・接近の度合い）。
- 既存効果音（`REPAIR_DONE` / `LIFTOFF` / `FANFARE`）の段階への割り当て妥当性。地球到達を強調する音の調整要否。
- 開発時に `ALL_CLEAR` を素早く再生するデバッグ手段の要否。
