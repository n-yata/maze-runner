# 要求内容

## 概要

ステージ3クリア後に、HP制の巨大ボスと一騎打ちする「ボスステージ」を最終関門として追加する。
ボスは盤面上部に陣取って弾幕を放ち、プレイヤーはフルーツ由来のレーザーで反撃してHPを削り、
電磁バリアで被弾を防ぐ。ボス撃破で既存の帰還エンディング（`ALL_CLEAR`）へ進む。

## 背景

現状は全3面がいずれも「エイリアン4体全滅で即クリア」で、ラスボス的な決着がない。
ステージ3はすでに「エイリアンの巣」テーマで、物語はクライマックス手前まで来ている。
帰還エンディングは作り込み済みのため、その**直前に手応えのある最終バトル**を置くことで、
プレイ全体の締まりと物語の山場を強化する。部品収集（3個）の枠組みは変えず、最終関門として上乗せする。

## 実装対象の機能

### 1. ボスステージへの遷移（最終関門化）

- ステージ3クリア後、帰還エンディングへ直行せず、ボスステージへ遷移する。
- ボスステージは通常面とは異なる「ボス戦」専用のフェーズ／盤面として表現する。
- ボスを撃破すると、既存の帰還エンディング（`ALL_CLEAR`）へ進む。
- 部品は従来どおり3面で3個回収のまま（ボスは部品を持たない）。

### 2. HP制ボスの撃破バトル

- ボスは固有のHPを持ち、攻撃が命中するごとにHPが減少し、0で撃破される。
- プレイヤーの主攻撃手段はレーザー（フルーツ取得で発動、進行方向＝上方へ自動連射）。
  レーザー命中でボスのHPを削る。
- ボスのHP残量がプレイヤーに視覚的に伝わる（HPバー等のUI）。
- 撃破時に演出（撃破エフェクト）を出し、エンディングへの接続を明確にする。

### 3. ボスの弾幕とプレイヤーの被弾

- ボスは盤面上部に陣取り、一定パターンで弾／ビーム（弾幕）を放つ。
- プレイヤーは弾幕を回避しながら反撃する。被弾するとミス（残機が1減る）。
- 電磁バリア（パワーエサで展開）中は飛来弾を防ぐ盾として機能する。
- 残機が0になればゲームオーバー（既存のゲームオーバー導線を流用）。

### 4. ボス戦の専用演出・UI

- ボス戦であることが分かる導入表示（例: WARNING / BOSS 等）と専用の盤面表現。
- ボス本体の描画（巨大エイリアン等、宇宙テーマに沿う）。
- ボスのHP表示。

## 受け入れ条件

### ボスステージへの遷移

- [ ] ステージ3をクリアすると、帰還エンディングではなくボスステージが開始される。
- [ ] ボスステージ突入時、部品の回収数は 3/3 のままで増減しない。
- [ ] ボスを撃破すると、既存の帰還エンディング（`ALL_CLEAR`）演出が再生される。
- [ ] ボスステージ中にゲームオーバーになった場合、既存のゲームオーバー画面へ遷移する。
- [ ] タイトルへ戻る／リスタート時、ボス戦の状態（ボスHP等）が初期化される。

### HP制ボスの撃破バトル

- [ ] ボスは初期HP（>0）を持ち、レーザー命中ごとにHPが規定量だけ減る。
- [ ] HPが0になった時点でボスが撃破され、撃破演出を経てエンディングへ遷移する。
- [ ] ボスのHPが0になるまでは、ステージはクリアにならない（早期クリアしない）。
- [ ] ボスのHP残量がUI（HPバー等）でプレイヤーに分かる。

### ボスの弾幕とプレイヤーの被弾

- [ ] ボスは一定間隔で弾／ビームを放ち、盤面に弾幕が表示される。
- [ ] プレイヤーがボスの弾に被弾するとミス（残機が1減る）になる。
- [ ] 電磁バリア展開中は被弾しても残機が減らない（弾を防ぐ）。
- [ ] 残機が0になるとゲームオーバーになる。

### ボス戦の専用演出・UI

- [ ] ボス戦開始時に、ボス戦と分かる導入表示が出る。
- [ ] ボス本体が盤面上部に描画される。
- [ ] 60fps を維持する（重い演出でフレーム落ちしない）。

## 成功指標

- 通しプレイで「ステージ1→2→3→ボス戦→撃破→帰還エンディング」の流れが破綻なく再生される。
- ボス戦が「避けて・撃ち込む」緊張感を持ち、即死でも作業でもない手応えになっている（定性）。
- 既存のステージ進行・部品収集・エンディングの挙動を壊さない（リグレッションなし）。

## スコープ外

以下はこのフェーズでは実装しません:

- 複数ボス／ボスの形態変化（多段階フェーズ）。今回は単体・単形態のボス。
- ボス撃破スコアのランキング・実績システム等の永続化拡張。
- 取り巻きの通常エイリアンとの混在（ボス単体に集中する方針）。
- 新規の外部アセット（画像・音源）への依存追加（既存の図形描画・効果音の流用を基本とする）。

## 未決事項

以下は `/add-feature` の設計フェーズで判断・確認する:

- ボスステージの表現方法: 新フェーズ（例: `BOSS`）を追加するか、`level==4` の特殊面として扱うか。
- ボスのHP値と、レーザー1発あたりのダメージ量（必要ヒット数のバランス）。
- 弾幕パターンの具体（弾速・発射間隔・本数・狙い撃ち/ばら撒き）と難易度調整。
- ボスの被弾判定（プレイヤー弾→ボス、ボス弾→プレイヤー）の当たり半径。
- ボス本体・弾・撃破の描画／効果音を既存資産でどう表現するか（`SoundKey` 追加の要否）。
- ボス戦盤面のマップ構成（既存マップ流用 or ボス専用レイアウト）。
