# 要求内容: ストーリーモード（宇宙船修理エンディング）

## 概要

既存のレベル進行（全3ステージ）の上に物語の文脈を重ね、ゲーム開始時にオープニング、各ステージ
クリアで宇宙船の部品を1個ずつ獲得、3部品すべて回収後に修理して飛び立つエンディングを表示する。
新規画像アセットは増やさず、Canvas テキストと簡易アニメ（既存のグロー/パネル/パーティクル）で表現する。

## 背景

ステラー・ランは「敵を全滅させればステージクリア」という宇宙テーマのパックマン系迷路ゲームで、
リスキンは済んでいるが**物語的な目的が無く、プレイの動機がスコアだけ**になっている。
そこに「宇宙船が故障して遭難 → 各ステージで敵を倒し部品を集める → 全部品が揃ったら修理して
飛び立つ」という一本のストーリーを乗せ、プレイ全体に始まりと終わりの意味づけを与える。

- スコア以外のプレイ動機（達成感・物語の結末）が無く、最後まで遊ぶ理由が薄い。
- 世界観（遭難した宇宙船 vs エイリアン）は設定済みだが、ゲーム内で語られていない。
- 既存実装に好都合な土台がすでにある:
  - `MAX_LEVEL = 3`（`src/constants.ts`）で3ステージ構成 → **3部品**にきれいに対応
  - `ALL_CLEAR` フェーズ（`src/types.ts` / `gameLoop.ts:206`）が既存 → エンディング演出に拡張できる
  - `glowText()` / `drawPanel()` / `drawTitle()` 等の汎用オーバーレイ描画が `renderer.ts` にある

## 実装対象の機能

### 1. オープニング演出
- TITLE でゲーム開始後、ステージ1の READY に入る前に、遭難の導入テキストを Canvas に表示する。
- 「宇宙船が故障し宇宙に取り残された。部品を回収し、機体を修理して脱出せよ」という趣旨の短い物語テキスト。
- 入力（スペース/タップ）またはタイムアウトで READY（ステージ1）へ遷移する。

### 2. 部品の収集（ステージクリア=1部品）
- 各ステージの敵全滅（既存のクリア条件）で宇宙船の部品を1個獲得する。
- 収集した部品数を `GameState` に保持し（0〜3、永続化しない）、HUD に進捗（例: 部品 1/3）を表示する。
- 既存の STAGE CLEAR オーバーレイに「部品 n/3 回収」の文言を添え、収集が視覚的に伝わるようにする
  （独立したナレーション画面は設けない）。

### 3. エンディング演出（修理して飛び立つ）
- 最終ステージ（レベル3）クリアで3部品が揃った時、既存 `ALL_CLEAR` を拡張したエンディングを表示する。
- 「修理 → 宇宙船が飛び立つ」流れを Canvas テキストと簡易アニメ（グロー/パーティクル）で表現する。
- 締めの物語テキストを表示した後、TITLE へ戻る（既存 `ALL_CLEAR` → 初期状態復帰の流れを踏襲）。

### 4. ストーリー状態のリセット
- ゲームオーバーやタイトルへの復帰時、部品数・ストーリー進行を初期状態（部品0）に戻す。
- 進捗は localStorage に保存せず、1プレイ内で完結する。

## 受け入れ条件

### オープニング演出
- [ ] TITLE でスペース/タップ後、ステージ1のプレイ開始前にオープニングテキストが表示される。
- [ ] オープニングは入力またはタイムアウトでステージ1（READY→PLAYING）へ遷移する。
- [ ] オープニングのテキストが遭難＝部品回収＝修理脱出という目的を伝える内容になっている。

### 部品の収集
- [ ] ステージの敵を全滅させると部品が1個加算され、HUD の部品進捗（n/3）が更新される。
- [ ] STAGE CLEAR 表示に「部品 n/3 回収」相当の文言が含まれる。
- [ ] 3ステージをクリアすると部品数が 3/3 になる。
- [ ] 既存のスコア・残機・ハイスコアの挙動は変わらない（リグレッションが無い）。

### エンディング演出
- [ ] レベル3クリア時、3部品が揃っていればエンディング演出（修理→飛び立ち→締めテキスト）が表示される。
- [ ] エンディングは一定時間後（または入力で）TITLE に戻る。
- [ ] エンディング表示時にハイスコアが正しく確定・保存される（既存挙動の維持）。

### リセット
- [ ] ゲームオーバー後やタイトル復帰後に新規プレイを始めると、部品数が 0/3 から開始される。
- [ ] リロードしても部品の収集状況は引き継がれない（永続化しない）。

## 成功指標

- 定性: プレイヤーがプレイ開始から終了まで「遭難→部品回収→修理脱出」という一貫した物語を体験できる。
- 定性: 新規画像アセットを追加せず、既存の描画ユーティリティ（`glowText`/`drawPanel`/パーティクル）の
  範囲で演出が完結している。
- 定量: 既存の自動テスト（vitest）がすべてグリーンのまま、ストーリー進行（部品加算・遷移）の
  ユニットテストが追加されている。

## スコープ外

以下はこのフェーズでは実装しません:

- ステージ間の独立したナレーション画面（演出はオープニングとエンディングのみ）。
- 収集進捗・ストーリー進行の localStorage 永続化（1プレイ完結）。
- 部品を敵ドロップや迷路内専用アイテムとして拾う方式（入手は「ステージクリア=1個」に限定）。
- 新規画像・音声アセットの追加、ステージ数（MAX_LEVEL）の変更。
- 分岐ストーリー・複数エンディング。
