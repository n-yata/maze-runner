# 要求内容

## 概要

ゲームの方向性を「エサ全取得でクリア」から「敵を全滅させてクリア」へ転換する。プレイヤーはフルーツ取得で一定時間レーザーを放てるようになり、それと既存のパワーエサ（怯えさせて食べる）の2手段で敵4体を撃破する。あわせてタイトル画面をマップ非表示のシンプル＆スタイリッシュな演出に刷新し、PWAアイコンを宇宙飛行士（ヘルメット姿）に変更する。

## 背景

現状のクリア条件は「盤面の通常エサ（ドット）をすべて取得すること」。これは古典的な迷路ゲームの定番だが、受動的な収集プレイに留まり、宇宙を舞台にした本作の「攻めの体験」を活かしきれていない。クリア条件を「敵全滅」に変え、フルーツをレーザー化することで、逃げて集める遊びから武器で倒す能動的な遊びへと体験を引き上げる。タイトル画面とアプリアイコンも、この新しい方向性に合うよう刷新する。

## 実装対象の機能

### 1. クリア条件の転換（敵全滅クリア）
- ステージクリアの判定を「通常エサ全取得」から「敵4体すべて撃破（VANISHED）」に変更する。
- 通常エサ（ドット）は盤面に残し、取得はスコア加算のみ。クリア条件には影響しない。
- 撃破済みの敵はそのステージ中は復活しない（既存の VANISHED 挙動を踏襲）。

### 2. フルーツのレーザー化（撃破手段その1）
- フルーツ取得時の効果を「得点ボーナス」から「一定時間レーザーを放てるパワーアップ」に変更する。
- レーザー発動中は、自機の進行方向へ自動で連射する（スマホ操作前提。プレイヤーは移動で狙いをつけるだけ）。
- レーザーが敵にヒットすると、その敵を即撃破（VANISHED、復活なし）する。
- フルーツは「敵を倒し切るまで」一定間隔で繰り返し出現する（取り逃しや撃ち漏らしでも詰まないようにする）。

### 3. パワーエサによる撃破（撃破手段その2・既存維持）
- 既存の「パワーエサで敵を怯えさせて食べる→即消滅」の仕組みを残し、レーザーと併用できる2つ目の撃破手段とする。

### 4. タイトル画面の刷新
- タイトル画面ではマップ（盤面）を表示しない。
- ロゴと光を中心とした、シンプル＆スタイリッシュな演出に刷新する。

### 5. PWAアイコンの変更
- PWAアイコン（192/512/apple-touch）に宇宙飛行士（ヘルメット姿）を描く。
- 既存のアイコン生成スクリプト（`scripts/generate-icons.js`）の構図を変更して再生成する。

## 受け入れ条件

### クリア条件の転換
- [ ] 敵4体すべてを撃破するとステージクリアになる。
- [ ] 通常エサをすべて取得してもクリアにならない（クリアは敵全滅でのみ成立）。
- [ ] 通常エサ取得でスコアが加算される。
- [ ] 撃破済みの敵はそのステージ中に復活しない。

### フルーツのレーザー化
- [ ] フルーツを取得すると一定時間レーザーモードになる（スコアボーナスは付与されない、または別途定義）。
- [ ] レーザーモード中、自機の進行方向に自動でレーザーが連射される。
- [ ] レーザーが敵に当たると敵が撃破（VANISHED）される。
- [ ] 敵が1体以上残っている限り、フルーツが一定間隔で繰り返し出現し、理論上必ず全滅できる（詰みが発生しない）。

### パワーエサによる撃破
- [ ] パワーエサを取得すると敵が怯え、接触で撃破できる（既存挙動が維持されている）。

### タイトル画面
- [ ] タイトル画面でマップが表示されない。
- [ ] ロゴ・光を中心としたシンプルな演出が表示される。
- [ ] 入力でゲーム開始できる（既存のタイトル→開始フローが維持されている）。

### PWAアイコン
- [ ] 192/512/apple-touch の各アイコンに宇宙飛行士（ヘルメット姿）が描かれている。
- [ ] manifest.json から参照されるアイコンが新しいものに更新されている。

## 成功指標

- 「敵を倒す」能動的なプレイ体験になり、クリアまでの行動が収集から戦闘へ変わる。
- レーザー方式・パワーエサ方式のどちらでも、また両者の併用でも、必ずステージをクリアできる（詰みゼロ）。
- 刷新したタイトル画面とアイコンが、宇宙テーマの世界観と一貫している。

## スコープ外

以下はこのフェーズでは実装しません:

- レーザーの発射方式の変更（ボタン発射・全方位など。今回は「進行方向への自動連射」のみ）。
- 通常エサの撤去や見た目の大幅変更（残してスコア要素として維持）。
- 敵のAI・出現数・新ステージの追加。
- マルチプレイ・ランキング等の新規システム。

## 未決事項（実装フェーズで判断・確認）

- レーザーの具体パラメータ（連射間隔・弾速・射程・持続時間）と当たり判定方式。
- フルーツ再出現の周期（取得後n秒ごと／盤面に無くなったら一定間隔で再配置 等）と、レーザー化に伴うフルーツのスコア有無。
- 既存のフルーツ出現ロジック（`src/fruit.ts` の閾値1回方式）を「繰り返し出現」へ変更する具体方式。
- タイトル画面の演出詳細（ロゴアニメーション・パーティクルの使い方）。
- レーザーモード中の自機・レーザーの視覚表現とサウンド。
- クリア条件変更に伴うテスト（`tests/` 配下）の更新範囲。
