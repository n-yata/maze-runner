# 要求内容

## 概要

ゲームの見た目・色・名前を「宇宙・スペース」テーマに着せ替え、パックマン色の強い現状から脱却してオリジナリティを出す。
ゲームルール・AI・スコア計算・マップ構造は一切変更せず、ビジュアルと UI のみを刷新する。
新タイトルは **ステラー・ラン / STELLAR RUN**。あわせてモバイルの仮想十字キー（Dパッド）を廃止し、空いた領域をマップ拡大に充てる。

## 背景

PRD（`docs/product-requirements.md`）では「オリジナル著作権対応 — タイトル・素材はすべてオリジナル制作」を掲げているが、
現状のビジュアルがパックマンに酷似している:

- 主人公が黄色い丸＋パクパクする口（`drawPlayer`）
- 敵が Blinky/Pinky/Inky/Clyde の 4 ゴーストでお化け型シルエット・原作配色（`drawGhost` / `GHOST_COLORS`）
- アイテムがチェリー/イチゴ等のフルーツ（`FRUIT_TABLE`）
- 青い迷路、タイトル「迷宮ラン」

このままでは「オリジナル」と言いにくい。ルールという面白さの核は維持しつつ、世界観・キャラクター・配色・名称を独自の宇宙テーマに
着せ替えることで、低リスク・短期間でオリジナリティを最大化する。
あわせて、モバイル UI の仮想十字キーは操作の主役がスワイプであるため不要であり、撤去してマップ表示領域を広げる。

## 実装対象の機能

### 1. 宇宙テーマ・ビジュアル刷新（Canvas 手続き描画を維持）

着せ替えマッピング:

| 要素 | 現状 | 刷新後 |
|------|------|--------|
| 主人公 | 黄色い丸＋パクパク口 | 宇宙船 / 探査ドローン（推進の向き＝進行方向） |
| 敵4体 | お化け型シルエット | エイリアン（色違いで個性維持。AI・内部名キーは不変、表示名のみ宇宙風） |
| ドット | 小さい丸 | エネルギー結晶 |
| パワーエサ | 大きい丸 | コア |
| フルーツ | チェリー/イチゴ等 | 宇宙アイテム（鉱石/コア等の色違い） |
| 壁・背景 | 青い迷路 | スペースコロニーの通路（パレット入れ替え。ステージ別配色も宇宙系へ） |
| タイトル | 迷宮ラン | ステラー・ラン / STELLAR RUN |

- 描画方式は現状の Canvas 手続き描画（`renderer.ts`）のまま。スプライト画像化（PNG/SVG）は行わない。
- カラーパレット（`COLORS` / `GHOST_COLORS` / `STAGE_WALL_COLORS` / `FRUIT_TABLE`）を宇宙テーマへ総入れ替え。
- イジケ・死亡・食べられ等の既存演出は、新モチーフでも破綻なく成立させる。

### 2. UI 刷新（仮想十字キー廃止 + マップ拡大）

- モバイルの仮想十字キー `#dpad`（`index.html` の HTML/CSS）と `main.ts` の `setupDpad()` を完全撤去する。
- Dパッドが占めていた縦領域を canvas（マップ）の拡大で埋める（`fitToViewport` のスケール調整）。
- 操作はスワイプ（タッチ）／キーボード（PC）のみとする。スワイプ入力は `input.ts` で window 全体に張られているため、
  Dパッド撤去後も操作は機能する。

### 3. 名称・メタ情報の更新

- タイトル画面表示（`drawTitle`）、HTML `<title>`、PWA 名（`manifest.json` / apple-mobile-web-app-title）を新タイトルへ。
- 必要に応じて PRD 等ドキュメントのタイトル表記を更新する。

## 受け入れ条件

### 宇宙テーマ・ビジュアル刷新
- [ ] 主人公が宇宙船/探査ドローンとして描画され、推進（向き）が進行方向に一致する
- [ ] 敵4体がエイリアンとして描画され、4色で互いに区別できる（AI 挙動は従来どおり）
- [ ] ドットがエネルギー結晶、パワーエサがコアとして描画される
- [ ] フルーツが宇宙アイテム（鉱石/コア等）としてレベル別に色違いで描画される
- [ ] 壁・背景が宇宙コロニー風のカラーパレットに変わり、ステージ別配色も宇宙系になる
- [ ] イジケ状態・死亡演出・食べられ（EATEN）表示が新モチーフでも破綻なく表示される

### UI 刷新
- [ ] タッチデバイス（`pointer: coarse`）で仮想十字キーが表示されない（`#dpad` が撤去されている）
- [ ] Dパッドが占めていた領域が canvas（マップ）の拡大で埋まり、縦の空白が残らない
- [ ] スワイプ操作で上下左右4方向の移動ができる（従来どおり）
- [ ] キーボード（矢印キー / WASD）で操作できる（従来どおり）

### 名称・メタ
- [ ] タイトル画面に「ステラー・ラン / STELLAR RUN」が表示される
- [ ] HTML `<title>` と PWA 名（manifest）が新タイトルになっている

### 回帰（不変であることの保証）
- [ ] ゲームルール（ドット収集・ステージクリア条件・残機・スコア計算）に変化がない
- [ ] ゴースト AI（Blinky/Pinky/Inky/Clyde の挙動）と内部名キー `GhostName` が不変
- [ ] マップ構造・タイル座標・当たり判定が不変
- [ ] 既存テスト（vitest）がすべて通る

## 成功指標

- 第三者が見て「パックマンのコピー」ではなく独自の宇宙ゲームと認識できる（定性）
- ビジュアル刷新による不具合・回帰がゼロ（既存テスト全通過 + 目視確認）
- モバイルで操作領域が広がり、マップがビューポートいっぱいに表示される（定性）

## スコープ外

以下はこのフェーズでは実装しません:

- ゲームメカニクス（ルール・AI・スコア・ステージ進行）の変更
- マップ構造・タイル座標・当たり判定の変更
- スプライト画像（PNG/SVG）化・外部アセット導入
- 新規 BGM・効果音の差し替え（音まわりは現状維持）
- 新ステージ・新キャラクター（敵の体数増減など）の追加
