# Requirements

## Request
- Polish the overall game feel and presentation.
- On smartphone/touch operation, show a virtual pad at the touched location.

## Acceptance Criteria
- Touch input shows a transient virtual pad centered at the initial touch point.
- The pad indicates the current held direction while the finger is moving.
- The pad hides after touch end/cancel and does not add fixed DOM D-pad controls.
- Game presentation gains small visual polish without changing core rules.
- TypeScript build, unit tests, and relevant E2E checks pass.
