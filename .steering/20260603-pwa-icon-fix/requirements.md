# 要求内容

## 概要

PWAアイコン（`icons/icon.svg` および生成PNG群）を、旧パックマン風デザインから現行の宇宙テーマ「ステラー・ラン」に合わせて刷新する。

## 背景

`672cf9f` でゲーム本体は宇宙テーマ「ステラー・ラン」へリスキン済みだが、PWAアイコンだけが旧パックマン風（黄色いパックマン・赤いゴースト・青壁 `#0000CC`・サーモン色ドット）のまま取り残されている。`manifest.json` の名称・説明は宇宙テーマに更新されているため、ホーム画面に追加した際のアイコンと実際のゲーム画面・名称が一致せず、ブランド体験が崩れている。

ゲーム本体の実際の配色・モチーフ（`src/constants.ts`, `src/renderer.ts`）にアイコンを揃える。

## 実装対象の機能

### 1. icon.svg の宇宙テーマ化
- 背景を深宇宙 `#05060F` に変更
- 枠をコロニー壁 `#2747C8` に変更
- 自機を「宇宙船」（機首 `#9FD0FF`・コックピット `#06324A`・推進炎 `#FF8A3C`）に変更
- 敵を「エイリアン」（ドーム頭＋触角＋大きな目、`#FF4D5E` / `#4DE0FF`）に変更
- ドットをエネルギー結晶（シアン `#7DF0FF`）／コア（`#FFE66D`）に変更

### 2. generate-icons.js の宇宙テーマ化
- SVGと視覚的に一致するように、PNG生成スクリプトの描画ロジックを宇宙テーマへ書き換える
- 192 / 512 / 180(apple-touch) の3サイズを再生成

## 受け入れ条件

### icon.svg の宇宙テーマ化
- [ ] 旧パックマン要素（黄パックマン・赤ゴースト・`#0000CC`壁・`#FFB8AE`ドット）がSVGから一掃されている
- [ ] 背景・枠・自機・敵・結晶の配色が `src/constants.ts` の宇宙テーマ値と一致している
- [ ] `viewBox="0 0 512 512"` を維持し、正方形で破綻なく表示される

### generate-icons.js の宇宙テーマ化
- [ ] 生成された3つのPNGがSVGと同じ宇宙テーマ構図になっている
- [ ] `node scripts/generate-icons.js` がエラーなく完走し、3ファイルを出力する
- [ ] 生成PNGを目視確認し、宇宙船・エイリアン・結晶が判別できる

## 成功指標

- ホーム画面アイコン（PNG）とゲーム本体・`manifest.json` の世界観が一致する
- 旧パックマン由来の色・モチーフがアイコン資産から完全に除去される

## スコープ外

以下はこのフェーズでは実装しません:

- `package.json` の `name` / `description`（内部メタ情報。アイコンとは別タスク）
- `manifest.json` の構造変更（アイコン参照は既に正しい）
- favicon の追加
- アイコンのアニメーション

## 参照ドキュメント

- `src/constants.ts` - 宇宙テーマの配色定義（COLORS / GHOST_COLORS）
- `src/renderer.ts` - 宇宙船・エイリアン・結晶の描画ロジック
- `manifest.json` - PWAマニフェスト
